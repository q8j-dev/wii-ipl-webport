Wii Menu 4.3U

This page runs the Wii System Menu 4.3U, but it does not include Nintendo's files. Provide the System Menu from your own Wii, as one of:

  • the System Menu 4.3U WAD (or a zip containing it), with the Wii common key
  • the nine decrypted contents 00000000.app … 00000008.app (or a zip of them)
  • nand.bin made by web/tools/mknand.py

Everything stays in this browser. Settings and saves made by the menu are kept between visits. Needs Chrome or Edge 137+ for full speed; other browsers use a slower fallback.
